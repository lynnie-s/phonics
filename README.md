# Phonics 小樂園

給小朋友的 phonics 練習網站:點單字聽發音、看 Alphablocks 影片、玩小測驗賺星星。

## 檔案
- `index.html`:網站本體
- `img/`:單字圖片(從教材裁出,共 547 張)

## 放上 GitHub Pages
1. 在 GitHub 建一個新 repo(例如 `phonics`),把 `index.html` 和整個 `img` 資料夾一起上傳。
2. Settings → Pages → Branch 選 `main` / root → Save。
3. 約一分鐘後網址是 `https://你的帳號.github.io/phonics/`

## 注意
`img/` 裡的圖片來自出版社教材,公開的 repo 等於公開散布。只給自己和學生用的話,建議用私人 repo。
